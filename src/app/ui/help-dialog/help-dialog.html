Shortcuts

How to use PaperLens

  • / focuses the search box.
  • ? opens this help.
  • Esc closes dialogs, the tour, and the paper drawer.

Queries use boolean syntax: AND, OR, parentheses, quotes, title:, authors:, yearPublished>, and _exists_:. A space means AND. NOT is applied to the sample set and to the “filter loaded results” box.

If the primary index is rate-limited or unauthenticated, PaperLens switches smoothly to the built-in sample set, marked "Sample data" on cards.
