Shortcuts

How to use PaperLens

  • / focuses the search box.
  • ? opens this help.
  • Esc closes dialogs, the tour, and the paper drawer.

Queries use CORE syntax: AND, OR, parentheses, quotes, title:, authors:, yearPublished>, and _exists_:. A space means AND. NOT is applied to the sample set and to the “filter loaded results” box.

If CORE is rate-limited or rejects a key, the banner switches to the built-in sample set. That set is marked Sample data on every card.
